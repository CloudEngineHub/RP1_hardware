## 工作表

两份文件均包含以下工作表，其他分类明细见文件内各工作表：

| 工作表 | 内容 |
| --- | --- |
| `总BOM` | 整机装配件、结构件、标准件、板卡、线束及外购件的料号、名称、数量、修订和材料信息 |
| `包材` | 包装物料清单 |

按所选配置使用对应 BOM，并通过料号查找配套资料。模型与加工文件见 [机械结构](../01_Mechanic/README.md)，板级 BOM 与生产文件见 [PCB](../02_PCB/README.md)，线束图纸与物料表见 [线束](../03_Harness/README.md)。
